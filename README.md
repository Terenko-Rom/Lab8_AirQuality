# Лабораторна робота №8
## Робота з базами даних через ORM

**Тема:** Система моніторингу якості повітря  
**Варіант:** 26  
**Мова програмування:** C++20  
**СУБД:** SQLite  
**ORM-бібліотека:** sqlite_orm  
**Середовище розробки:** Visual Studio 2022

## Опис проєкту

Програма призначена для роботи з базою даних системи моніторингу якості повітря. Вона дозволяє зберігати інформацію про датчики та результати вимірювання показників якості повітря.

У базі даних використовуються дві основні сутності:

- **Sensor** — інформація про датчики: назва, місце розташування, модель та статус.
- **AirQualityIndicator** — результати вимірювань: дата, PM2.5, PM10, CO2 та індекс якості повітря AQI.

Для взаємодії з базою даних використовується SQLite та бібліотека sqlite_orm.

## Реалізовані можливості

- Створення та ініціалізація бази даних.
- Додавання, отримання, оновлення та видалення датчиків.
- Додавання та отримання результатів вимірювань.
- Фільтрація даних за датчиком та значенням AQI.
- Сортування вимірювань за рівнем PM2.5.
- Отримання останніх вимірювань.
- Об'єднання таблиць за допомогою JOIN.
- Обчислення середнього PM2.5, максимального PM10 та кількості записів.
- Перевірка транзакцій COMMIT і ROLLBACK.
- Порівняння швидкодії SQLite C API та sqlite_orm.

## Структура проєкту

- `Lab8_AirQuality.cpp` — головний файл програми.
- `include/` — заголовні файли моделей, бази даних та репозиторіїв.
- `src/` — реалізація роботи з базою даних, репозиторіями та порівняння SQLite C API з ORM.
- `CMakeLists.txt` — конфігурація збирання проєкту.
- `CMakePresets.json` — налаштування конфігурацій CMake.
- `vcpkg.json` — перелік необхідних залежностей.

## Збирання та запуск

Для роботи з проєктом потрібні Visual Studio 2022 з підтримкою C++, CMake та vcpkg.

Після клонування репозиторію необхідно відкрити папку проєкту у Visual Studio 2022.

У терміналі PowerShell, перебуваючи в кореневій папці проєкту, встановити залежності командою:

`& "C:\Program Files\Microsoft Visual Studio\2022\Community\VC\vcpkg\vcpkg.exe" install`

Після встановлення залежностей потрібно дочекатися конфігурації CMake, вибрати конфігурацію `x64-debug` та виконати збирання проєкту.

Для запуску програми необхідно виконати ціль `Lab8_AirQuality`.
